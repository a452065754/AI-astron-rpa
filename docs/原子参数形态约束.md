# AI 生成原子节点的参数形态约束（强制）

> 2026-11-04 由「sfsc 改 0 报脚本数据为空」「设计器输入内容整行消失」两个实锤案例提炼。
> **总约束：AI 生成的节点，在设计器参数面板上必须与手动添加同一原子时看到的一致** ——
> 参数一行不少、值可改、改完保存不坏。任何为"省事"而偏离框架默认形态的做法都是雷。

## R1 · 被 dynamics 显示条件引用的参数，必须落库为「裸标量」

- **现象**：`fill_type` 落成数组 → 设计器「输入内容」整行消失；`input_type` 落成数组 →
  js_run 运行报「脚本数据为空」。
- **根因**：原子 schema 里 `fill_input.dynamics = "return $this.fill_type.value == 'text'"`。
  设计器前端（`selfExecuting.ts`）求值 `$this.<key>.value` 取 value **原样**：数组 ≠ 字符串 →
  下游参数 `show=False`。
- **连锁后果**：引擎 `params.py:parse_input` 对 `show=False` 的参数**直接跳过不传**；
  且设计器**每次保存都会重算 dynamics 并把 show 回写存盘**——用户保存一次就永久坏。
- **约束**：构建节点时扫描原子 schema 所有 dynamics 表达式里的 `$this.<name>.value`，
  被引用参数（如 `fill_type`/`input_type`/`simulate_flag`/`get_type`）落库为裸标量
  （`"text"`、`True`、`15`），不包数组。
- **实现**：`flow_generator._collect_dynamics_refs()`（生成侧）+ `validate` R1 校验（拦截侧）。
- **波及面**：全库 357 原子中 **143 个（40%）** 存在此结构；Browser 系 14 个原子全部命中。

## R2 · show 的语义 = 引擎跳过该参数

`show=False` 不是纯 UI 概念：引擎把它当「隐藏字段」直接不传，下游原子拿到默认空值。
所以**任何导致 show 被算成 False 的落库形态都是运行时炸弹**，不只是显示问题。

## R3 · 流程参数不能烘焙成字面量，必须保留 `p_var` 引用

- **现象**：参数面板把 `sfsc` 改成 0，模块里读到的仍是落库时的 1。
- **根因**：引擎把流程参数生成为 `main()` 帧的**局部变量**（`sfsc = args.get("sfsc", ...)`），
  `ComplexParamParser` 把 `{"rpa":"special","value":[{"type":"p_var","value":"sfsc"}]}`
  编译成裸表达式 `sfsc`，在 main 帧求值 → 拿到面板当前值。烘焙掉引用 = 值写死。
  **`gv` 是空的**（`package.py` 只有 `gv = {}`），别指望 gv。
- **约束**：`$p:x` 一律转 `rpa:special(p_var)` 引用保留；js_run 的 `params`、
  `Script.module` 的 `module_param` 同理。
- **实现**：`build_module_param_items` / js_run params 分支的 `_contains_param_ref` 判断。

## R4 · 参数取值禁止 `x or 默认值`，必须显式判空

Python 里 `0 or "1" == "1"`：数值 0 有语义的参数（sfsc、batch_size…）用 or 兜底会
**静默把 0 改回默认**，不报任何错。统一用 `_get(ns, key, default)`（只在 None/空串回退）。
模块内兜底默认值必须与流程参数 default 一致。

## R5 · 复杂 JSON 参数（`$json:`）的两种合法形态

- 含循环变量 / 流程参数引用 → JSON 字符串 + `need_parse:"json_str"` + 保留 `rpa:special` 引用；
- 纯字面量 → 烘焙成**纯 JSON 字符串**（不带 need_parse、不带嵌套 rpa:special）。
  嵌套 rpa:special 会被设计器保存时剥掉 value 数组 → 引擎解析失败连带清空节点。

## R6 · 改了模块/参数后必须清编译缓存再真跑

`venvs/<robotId>/astron/main.py`、`package.py`、`__pycache__` 是编译产物，真跑会**复用旧的**。
清掉再跑，否则验证的是过期代码（踩过一次，浪费时间）。

## R7 · 参数默认值禁止绝对路径；代码必须对目录创建失败降级

`out_dir = F:\AI-Workbench\...` 换设备直接 `[WinError 3]`。默认值用相对/空，代码里
`makedirs` 失败降级为仅引擎日志，不中断流程。

## R8 · 环境差异参数化

浏览器类型（chrome/edge）等**依赖目标设备安装情况**的取值，做成流程参数而非硬编码。

## R9 · 红线：设计器打开旧流程后关闭会覆盖服务端

设计器关闭流程时把内存旧内容回存。AI 落库前必须确认设计器里没有开着该流程；
落库后可用 `check_flow.py` 核对。

## 自检（已固化进 `flow_generator.validate`）

- **R1 拦截**：dynamics 引用参数若落成数组 → error；引用形态 → warning；
- **裸标量枚举校验**：裸标量取值也必须在原子 options 内（`"bogus"` 会被拦）；
- 常规校验（必填参数、p_var 声明、元素归属、读取路径存在性）不变。
