## 5. 关键约定（别破坏）

1. **一条流程一个同名机器人**（历史约定）。同一机器人放多条流程会让「编辑」打开时不知道看哪个。
2. **内容写主流程**，不写子流程——设计器「编辑」默认打开主流程，写子流程用户看到空白。
3. **元素按 robotId 隔离**，必须挂在该流程自己的机器人下（坑 126）。
4. **`--robot-name` 优先于 `--robot-id`**：换设备时用名字，别抄旧 id。
